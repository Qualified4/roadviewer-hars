# 구현 및 검증 현황

현재는 **부분 구현 alpha**이다. 전체 이식, 성능 비교, 운영 가능 상태가 아니다. 원본 28개 Python 모듈과 53개 API 등록 항목, 105개 테스트 파일을 조사한 기준 목록은 `inventory.json`에 있다. 테스트 파일 수는 테스트 케이스 수와 다르다.

미이식 라우트는 `501 feature_not_ported`를 반환한다. 새 설치는 자동 변환을 기본으로 하며, 기존에 저장한 설정은 유지한다. 업로드 수신 중 자동 변환은 대기하고 수동 변환은 실행할 수 있다. 운영 전환과 전체 제품 이식의 완료를 뜻하지 않는다.

## 후속 작업 우선순위

1. 저널 복구/중복 등록/예약 경쟁과 구체적인 원본 오류 응답을 검증한다.
2. 변환 큐의 강제 종료/동시 취소/디스크 부족 경계와 추가 차량 코퍼스를 검증한다.
3. 가변 간격 HEVC 패킷 매핑, 역변환·다운로드를 완성한다.
4. 원격 저장소·재시도·무결성·보충 변환·보호된 정리를 이식한다.
5. 전체 API 및 UI 동등성·실제 업로더·실제 로그/영상·HAOS를 검증한다.
6. 같은 조건에서 성능을 비교하고 수치와 측정 아티팩트를 보존한다.

운영 포트 승계, Python 설정 변경, openpilot 목적지 변경은 실행하지 않는다.

상세 증거: [VALIDATION.md](VALIDATION.md), 측정 조건과 원시 결과: [PERFORMANCE.md](PERFORMANCE.md).

## alpha.2 재생 변환 검증 (2026-11-15)

실제61구간(모델72749프레임), 그 중 와이드26구간의 캐시 키를 제외한 replay/telemetry/track/summary를 Python 원본과 자동 비교했다. 1e-6 초과 차이는 없다. 원본은 읽기 전용이며 결과와 좌표 원문은 저장소에 올리지 않는다. 별도 루프백 서버에 실제3파일/4파일 업로드 후 자동 변환, 업로드 대기, 실제 전방/qcamera/와이드 브라우저 재생·일시정지·탐색·지도·오버레이·차량 그래프를 확인했다. 상세 범위와 남은 항목은 VALIDATION.md를 따른다. alpha.2 정식 배포/최신 CI 성공 여부는 별도 확인이 필요하다.
