# 구현 및 검증 현황

현재는 **부분 구현 alpha**이다. 전체 이식, 성능 비교, 운영 가능 상태가 아니다. 원본 28개 Python 모듈과 53개 API 등록 항목, 105개 테스트 파일을 조사한 기준 목록은 `inventory.json`에 있다. 테스트 파일 수는 테스트 케이스 수와 다르다.

미이식 라우트는 `501 feature_not_ported`를 반환한다. 변환 기능은 준비되지 않았으므로 새 업로드를 `unconverted`로 보존한다. 성공한 원시 로그 읽기를 UI 재생 변환 완료로 표시하지 않는다. 처리 설정을 바꾼 것처럼 응답하지 않는다.

## 후속 작업 우선순위

1. 저널 복구/중복 등록/예약 경쟁과 구체적인 원본 오류 응답을 검증한다.
2. 선택 필드 디코딩·텔레메트리·조향·overlay·CCNC·GPS·wall clock·replayV2 생성과 변환 큐를 이식한다.
3. 가변 간격 HEVC 패킷 매핑, 역변환·다운로드를 완성한다.
4. 원격 저장소·재시도·무결성·보충 변환·보호된 정리를 이식한다.
5. 전체 API 및 UI 동등성·실제 업로더·실제 로그/영상·HAOS를 검증한다.
6. 같은 조건에서 성능을 비교하고 수치와 측정 아티팩트를 보존한다.

운영 포트 승계, Python 설정 변경, openpilot 목적지 변경은 실행하지 않는다.
