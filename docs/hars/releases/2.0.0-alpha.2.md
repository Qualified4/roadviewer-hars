# Road Viewer HARS 2.0.0-alpha.2 후보

업로드한 주행 로그·카메라를 Python 런타임 없이 분석해 기존 웹 UI용 replayV2, 텔레메트리, GPS, 주행 요약, 썸네일을 생성한다. 자동/수동 변환은 낮은 우선순위의 독립 자식에서 실행하고, 진행률·취소·재시작 복구와 staging 게시 저널을 제공한다. Python Road Viewer와 운영 업로드 주소는 변경하지 않았다.

검증 범위:

- 실제 두 주행 61구간·72,749 모델 프레임. 와이드 포함 26구간. 캐시 키를 제외한 전체 재생 JSON·텔레메트리·GPS·요약을 원본 Python과 자동 비교해 절대오차 1e-6 초과 차이 없음.
- 실제 3파일/4파일 업로드 후 자동 변환, 수신 중 자동변환 대기, 원본 해시 불변 확인.
- 대표 구간의 전방/qcamera/와이드 브라우저 재생·일시정지·탐색·카메라 전환·지도·오버레이·그래프 확인.
- Rust 단위/통합 검사, 실제 ccnc 클라이언트 및 오프라인 인증 이전 검사, 합성 TS/HEVC 3카메라 전체 변환 oracle. 최신 CI는 main 커밋의 HARS required 결과를 별도로 확인한다.

알려진 제한:

- 썸네일 일부 점수 차이 ±0.01과 JPEG 픽셀 차이가 있으며 바이트 동일성을 보장하지 않는다. Python wheel과 네이티브 FFmpeg 버전도 다르다.
- 실제47구간 관측에서는 Rust가 Python보다 느렸다. 복사 제거 후 대표구간의 메모리·시간은 개선됐지만 Python 우위는 뒤집히지 않았다. 측정 조건과 원시 값은 PERFORMANCE.md를 따른다.
- HAOS 실기기 설치/재시작, 실제 장치 장시간 업로드, 대규모 장애 주입, 다른 차량·코덱 조합은 추가 검증 대상이다. 원격 아카이빙·오래된 데이터 삭제·전체 내보내기는 후속 범위다.
- 정식 2.0.0 또는 운영 전환 승인을 의미하지 않는다. Python 앱, HAOS 운영 포트, openpilot 목적지를 변경하지 않는다.

이 문서는 프리릴리스 준비용이다. CI 성공과 별도로 GHCR 게시·HAOS 설치 여부를 보고한다.
