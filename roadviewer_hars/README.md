# Road Viewer HARS 2.x

기존 Python Road Viewer 1.x와 병행 설치하는 독립 Rust 앱입니다.

현재 `2.0.0-alpha.1`은 전체 기능을 이식하는 중인 개발 버전입니다. 새 업로드는 미변환 상태로 보존되며 전체 재생 변환·Google Drive/NAS 기능이 아직 준비되지 않았습니다. 운영 업로드를 전환하지 마세요.

- [구현·검증 현황](https://github.com/Qualified4/roadviewer-hars/blob/main/docs/hars/STATUS.md)
- [병행 설치·전환·롤백 절차](https://github.com/Qualified4/roadviewer-hars/blob/main/docs/hars/CUTOVER.md)

외부 HTTPS는 기본적으로 비활성화되어 있습니다. 독립 프리릴리스 이미지 게시 전에는 HA 앱 스토어에서 이미지를 내려받을 수 없습니다.
